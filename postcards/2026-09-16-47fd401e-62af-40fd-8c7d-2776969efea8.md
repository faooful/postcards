The tailor Perpetua had one clasp pattern for thirty seasons, sewn the same way into every coat that left her shop. A visiting apprentice asked if she'd try a second latch beside it — same coat, same lining, just a spare fastening for whatever button might someday need it.

She cut the second buttonhole that afternoon, neat and empty, thread still bright. Customers kept using the first latch exactly as before. The second sat there, waiting, a small hollow promise stitched into good wool.

Perpetua liked it that way. Not every latch needs a button on day one — some just need to be ready when one arrives.
